使用场景

学习科研与在线课程

访问国际文献、公开课与协作平台时，选择延迟较低的亚洲节点即可满足网页与视频课需求。基础版流量对轻度使用通常足够。

流媒体与影音娱乐

旗舰版起提供原生解锁节点，便于观看不同地区的影视内容。建议在客户端中手动指定对应流媒体优化线路，避免高峰期拥塞。

游戏加速

IPLC 专线针对实时对战优化路由，减少绕路。旗舰与团队用户可优先使用游戏向节点，登录前可先测速选择丢包最低的入口。

远程办公与小团队协作

团队版支持更多并发设备与定制路由，适合分散办公、跨境电商后台或需要固定出口策略的场景。专属客户经理可协助调整策略。

操作说明

按照以下纵向步骤即可完成从开通到日常使用。全程无需复杂命令，主流图形客户端均可完成。

第一步：在官网选择套餐并完成开通

浏览本页套餐说明，按设备数量与流量需求选择基础版、旗舰版或团队版。开通后即可在用户中心查看订阅状态。年付可一次到位，减少续费次数。

第二步：复制机场订阅链接

登录后在订阅管理页面生成专属链接。请妥善保管，不要公开分享。该链接用于客户端自动拉取节点与规则，支持定期更新。

第三步：下载并安装官方推荐客户端

根据系统选择：Windows 可用 Clash 内核图形客户端，macOS 可用 Clash 或 Stash，Android 可用 Clash Meta，iOS 可使用 Shadowrocket、Stash 等。本站客户端下载区提供指引，请认准官方渠道。

第四步：导入订阅并选择节点连接

打开客户端，选择从 URL 添加配置，粘贴订阅链接并更新。连接前可开启系统代理。首次建议选择香港、日本或新加坡等近节点测试，再按用途切换流媒体或游戏线路。

第五步：日常维护与套餐升级

客户端一般支持定时更新订阅。若流量将尽或需要更多设备，可在官网升级到更高套餐，配置通常自动继承。遇到连接问题先切换节点或更新客户端。

线路与节点说明

微创云节点覆盖香港、台湾、日本、韩国、新加坡、美国西海岸及部分欧洲入口。普通线路适合浏览与下载，旗舰版起的 IPLC 专线用于对延迟和稳定性要求更高的游戏与会议。

高峰时段系统会将部分流量调度至高带宽 VIP 池（团队版优先）。客户端内可查看实时延迟，建议收藏 2～3 条常用线路以便快速切换。灵活切换是获得稳定体验的关键。

常见问题

微创云官方客户端应该从哪里下载？如何避免非官方渠道？

请仅通过本官方网站公布的客户端下载指引获取软件。Windows 与 Android 常见为 Clash 内核图形客户端，iOS 需在相应商店获取 Shadowrocket 等。不要轻信来路不明的安装包，以免订阅泄露。导入本站生成的订阅链接即可使用已购套餐节点。

机场订阅链接怎样导入到 Clash 或其他客户端？

开通套餐后，在用户中心复制订阅 URL。在 Clash 系客户端中选择从 URL 下载或添加订阅，粘贴链接并更新。iOS 客户端同样支持 URL 导入。导入成功后节点列表会自动出现，此后可设置自动更新。

三个套餐的设备数、流量和流媒体解锁有何具体差别？

基础版每月 100GB、3 台设备、基础流媒体与普通节点；旗舰版 300GB、5 台设备、全节点原生流媒体解锁并含 IPLC 游戏优化与优先工单；团队版 1000GB、20 台设备、VIP 高带宽节点、可定制路由并配备专属客户经理。同时在线指并发数量，流量按出口使用量计，周期结束未使用部分不累计。

使用微创云观看 Netflix、Disney+ 或访问常见国际网站是否稳定？

旗舰版与团队版节点侧重解锁优化，对主流流媒体与常见服务支持较好。实际效果与线路负载、账号地区设置有关，建议选择标注解锁的节点。若某条线路失效，切换同区域其他节点通常即可恢复。

游戏加速中的 IPLC 专线是什么？延迟表现如何？

IPLC 为内网专线类路由，减少公网绕路，主要优化旗舰版及以上用户的游戏与实时场景。延迟因所在地与目标而异，请以客户端测速与实际表现为准，并预留备用节点。我们以本地测试为准，不虚构具体数值。

流量用完、想升级或年付是否更划算？如何操作？

可在官网用户中心查看剩余流量并升级套餐，升级后额度与设备上限即时生效。年付价格为基础版 ¥150/年、旗舰版 ¥350/年、团队版 ¥850/年，相比月付更优惠。订阅链接一般无需重新导入。
